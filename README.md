# AGENTHUB-4GEEKS# AgentHub — Panel de Administración

Prototipo frontend para una plataforma SaaS de alquiler y gestión de agentes de inteligencia artificial.

## Descripción

AgentHub permite a empresas gestionar agentes IA, sus skills, contrataciones, usuarios y errores desde un panel administrativo centralizado.

Este proyecto fue desarrollado como prototipo visual y funcional, sin backend ni conexión a APIs.

## Tecnologías utilizadas

- HTML5
- Tailwind CSS mediante CDN
- JavaScript vanilla
- Datos hardcodeados

## Funcionalidades

El panel incluye:

- Dashboard con métricas generales
- Gestión de usuarios
- Gestión de agentes IA
- Catálogo de skills
- Contrataciones de agentes
- Log de errores
- Modo claro y oscuro
- Dropdowns de acciones
- Modales de detalle
- Skills expandibles
- Diseño responsive
